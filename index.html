How To Use This Tool

Two paths to generate test data — choose the one that fits your situation.

📄 Path A — Import from OpenAPI / Swagger Spec

Already have an API spec file? Start here. All $ref references are resolved automatically.

  1. 1 Open the app → click "OpenAPI Import" tab Available at localhost:8080 after starting the app.
  2. 2 Paste or upload your spec Supports OpenAPI 3.0 / 3.1 in YAML or JSON format.
  3. 3 Click "Parse Spec" All operations are listed in a dropdown. $ref resolution is automatic.
  4. 4 Select the operation e.g. POST /productOrder – createProductOrder
  5. 5 Choose direction & count Request Body or Response Body. Set how many records to generate.
  6. 6 Click "Generate Schema" OpenAPI schema is converted to generator format automatically.
  7. 7 Click "Generate Data" in the Generator tab Realistic test data is created matching your API's schema.
  8. 8 Copy or Download the JSON output Ready for Postman, Cucumber, JMeter, or any test tool.

✏️ Path B — Write or Derive Schema Manually

No spec file? Build from scratch or infer from a sample API response.

  1. 1 Open the app → use the "Generator" tab This is the default active tab when you open the tool.
  2. 2 Load a template or write your schema Pick from Simple Order, Complex Order, Users, or Products.
  3. 3 — OR — paste a sample API response Paste any real JSON response into the "Sample Response" box.
  4. 4 Click "Sample → Schema" Field types are inferred from values and field names automatically.
  5. 5 Add business rules & edge cases (optional) Use computedFields, qaMode, and seed for richer datasets.
  6. 6 Click "Generate Data" A JSON array of records appears in the output panel.
  7. 7 Copy or Download the output Use "Output → Schema" to refine the schema from results.
💡 Pro tip: Both paths converge at the Generator tab. Add computedFields for business rules (taxes, totals), enable qaMode for boundary edge cases, or set a seed to reproduce the exact same dataset every run.

Current Limitations

Transparent boundaries help teams adopt confidently and prioritize roadmap work.

Expression & Modeling Constraints

  • No nested expression language or advanced logical operators.
  • No relational cross-dataset constraints (foreign key style links).
  • No custom plugin hooks for generator extensions.

Platform Constraints

  • JSON output only; no direct database write mode.
  • Single locale default (en_US).
  • Synchronous request-response generation model.

API & Local Run

Endpoints

POST /api/generate — Generate records from schema payload.

POST /api/openapi/parse — Parse an OpenAPI spec; returns list of operations.

POST /api/openapi/schema — Extract & convert schema for a specific operation.

GET /api/health — Service health check.

Local App URL

http://localhost:8080
