Schema Patterns

Simple Field (String Type):
"firstName": "firstname",
"email": "email",
"uuid": "uuid"
Number Field:
"age": {"type": "number", "min": 18, "max": 65}
Decimal (Money):
"price": {"type": "decimal", "min": 10.5, "max": 999.99, "decimals": 2}
Nested Array:
"items": {
 "type": "array", "minItems": 1, "maxItems": 5,
 "schema": {"name": "productname", "qty": {"type": "number", "min": 1, "max": 10}}
}

Business Rule Expressions

Arithmetic:
"doubled_price": "price * 2",
"discounted": "price * 0.9",
"total": "subtotal + tax + shipping"
Conditionals:
"shipping": "if(subtotal > 100, 0, 15)",
"priority": "if(amount > 5000, 'HIGH', 'NORMAL')"
Array Aggregation:
"order_total": "sum(items[].price * items[].quantity)",
"tax_amount": "sum(items[].tax)"

📖 About This Tool

What is it?

The Intelligent Test Data Generator is a Spring Boot application that creates realistic, business-rule-validated test data for QA, development, and performance testing. It supports complex schemas, nested arrays, computed fields, and automatic edge case generation.

✅ Key Capabilities

  • Generate 1-100,000 records with realistic data
  • Complex nested schemas with arrays and objects
  • Business rule expressions: arithmetic, conditionals, array aggregation
  • Automatic edge case generation for QA testing (min/max/boundary values)
  • Reproducible data using seed values
  • 50+ data types: names, emails, phones, UUIDs, products, companies
  • QA metadata tracking on every generated record
  • JSON output ready for API testing and database imports

⚠️ Known Limitations

  • No custom Faker generation logic (built-in types only)
  • Basic expression language (no nested functions)
  • No relational constraints between records
  • No regex pattern matching for data generation
  • No direct database integration (JSON output only)
  • No asynchronous/streaming (all data generated synchronously)
  • No scheduling capability for recurring generation
  • Single locale (hardcoded to en_US)
  • Limited edge case types (4 predefined)

🎯 Use Cases

  • QA Testing: Generate diverse test datasets with business rule validation and edge cases
  • Development: Pre-populate dev databases, create API mock payloads, test nested structures
  • Load Testing: Generate 10K-100K consistent records to benchmark database and API performance
  • API Documentation: Create realistic example payloads for API docs
  • Migration Testing: Generate test data that matches production patterns
